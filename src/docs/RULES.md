# Regulile jocului — Duelul Regatelor

**Regulile se rescriu.** Modelul de până acum — un singur ordin pe rundă, din
cinci, cu efecte fixe, și aur care urca singur nivelul de echipament — a fost
șters din cod. Ce urmează în locul lui:

- oastea se împarte pe mai multe direcții în aceeași rundă, iar fiecare direcție
  răspunde proporțional cu soldații primiți;
- aurul se cheltuiește deliberat, nu se transformă automat în putere;
- expedițiile se întâlnesc pe drum, iar o parte din armată se întoarce acasă.

Documentul se completează pe măsură ce fiecare regulă se așază, iar la final
descrie din nou tot ce decide o rundă. Până atunci, singura descriere exactă a
jocului e codul din `KingdomDuel.Domain`.
